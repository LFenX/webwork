# 02 - MVP 范围与阶段边界

## 1. MVP 总目标

第一版 SQL Guardian 要实现一个“可上线、可体验、可继续扩展”的基础形态：

- 它有一个家。
- 它能在全站出现。
- 它能动、能说话、能聊天。
- 它有每个用户独立的资料、等级、心情、人格参数。
- 它能保存低风险记忆。
- 它能影响 SQL Assistant 的回答风格。
- 它不会破坏 SQL Lab、SoulWing、权限、审计、移动端和性能。

第一版不是完整游戏，不追求所有剧情和高级形态一次上线。

## 2. MVP 用户故事

### 2.1 全站陪伴

作为用户，我登录网站后，能在页面边缘看到一个小小的 SQL Guardian。它不会挡住我操作，但会偶尔表现出待机、发呆、走动、思考等动作。

验收：

- 登录用户可见。
- 未登录用户不可见或只显示无个人数据的占位入口。
- 用户可隐藏。
- 动画不遮挡主操作区域。

### 2.2 SQL Lab 角色之家

作为用户，我打开 SQL Lab 时，能在 SQL Assistant 区域看到它的“家”。点击后，角色会出来说话，并进入 SQL 相关对话。

验收：

- SQL Assistant 原有功能不受影响。
- 角色之家可点击。
- SQL Lab 页面中角色默认进入“专业 / 查询模式”。
- 不影响编辑器、结果表格、Schema 树。

### 2.3 对话

作为用户，我能和 Guardian 聊天。它的回答有角色性格，但也知道当前页面上下文。

验收：

- 输入消息后能得到 AI 回复。
- 对话保存在 GuardianDialogue。
- 回复会体现当前人格参数。
- 涉及 SQL 时不绕过 SQL 安全规则。

### 2.4 记忆

作为用户，我告诉它一些偏好，例如“我喜欢你叫我 LFen”，它能在之后自然提起。

验收：

- 低风险偏好可保存。
- 用户可查看记忆。
- 用户可删除记忆。
- 敏感信息不自动保存。

### 2.5 成长

作为用户，我在站内写文章、运行 SQL、更新简历、与 Guardian 对话时，它会获得经验值并逐渐升级。

验收：

- 用户活动产生 GuardianEvent。
- 经验值会累积。
- 达到阈值会升级。
- 升级有提示或台词。
- 等级持久化。

### 2.6 SQL Assistant 风格融合

作为用户，我使用 SQL Assistant 时，会感受到它不再是冷冰冰的工具，而是 Guardian 在协助我。但它仍然专业、准确、安全。

验收：

- SQL Assistant 能读取 Guardian persona context。
- 回答风格轻微人格化。
- SQL 生成准确性和安全边界不下降。
- 对危险 SQL 仍然拒绝或提醒。

## 3. MVP 功能清单

### 3.1 必须完成

| 功能 | 描述 |
|---|---|
| GuardianHost | 全站浮层宿主，控制显示、位置、状态 |
| GuardianHome | 角色之家入口，重点出现在 SQL Assistant 区域 |
| GuardianSprite | 2D 角色展示，支持基础动作状态 |
| GuardianBubble | 对话气泡，支持短句、自言自语、提示 |
| GuardianChatPanel | 用户与角色对话面板 |
| 状态机 | idle、walk、jump、think、talk、sleep、teleport、level-up |
| Profile API | 获取和更新每用户独立 GuardianProfile |
| Event API | 记录用户行为并计算经验 |
| Memory API | 保存、列表、删除 Guardian 记忆 |
| Chat API | 与 Guardian 对话，保存对话 |
| SQL Assistant Context | 给 SQL Assistant 注入人格上下文 |
| 设置开关 | 显示开关、动画开关、记忆开关 |
| Reduced Motion | 尊重用户系统动画偏好 |

### 3.2 可以延后

| 功能 | 延后原因 |
|---|---|
| 完整剧情副本 | 需要更多内容设计 |
| 多套角色皮肤 | 依赖美术资产 |
| Rive/Lottie 高级动画 | MVP 可用 SVG/CSS 占位 |
| 复杂物理碰撞 | 第一版使用边缘路径和避让规则即可 |
| 多角色社交 | 当前只做每用户一个 Guardian |
| 管理后台统计 | 上线后再补充 |
| 语音 | 文本气泡优先 |
| 宠物背包 / 技能树 | 成长系统稳定后再做 |

### 3.3 明确不做

- 不做抽卡。
- 不做付费强化。
- 不做会遮挡主界面的强提醒。
- 不做角色版权仿制。
- 不做跨用户记忆共享。
- 不做管理员绕过用户记忆权限。
- 不做 SQL 权限绕过。

## 4. 第一版页面行为

### 4.1 SQL Lab

默认表现：

- GuardianHome 显示在 SQL Assistant 面板标题栏右侧。
- GuardianSprite 可在右侧面板边缘待机。
- 用户点击“Run”后，Guardian 进入 thinking。
- 查询成功后，Guardian happy。
- 查询失败后，Guardian confused，并可以提示“要不要让我帮你看看这句 SQL？”
- 用户打开 SQL Assistant 时，Guardian 可用角色口吻引导。

### 4.2 首页

默认表现：

- Guardian 在页面右下或右侧边缘待机。
- 可根据最近活动说简短台词。
- 不主动展开长对话。

### 4.3 内容页

默认表现：

- 写文章时保持低干扰。
- 用户停顿较久时，可以提示“卡住了吗？要不要让我帮你整理思路？”
- 不自动修改内容。

### 4.4 简历和求职页

默认表现：

- 角色以鼓励、复盘、提醒为主。
- 不提供过于频繁的建议。
- 不自动改简历，除非用户明确要求。

### 4.5 聊天页

默认表现：

- 默认安静。
- 不读取或总结聊天内容，除非用户显式要求且权限允许。
- 不打断用户与真实好友聊天。

## 5. 角色状态 MVP

| 状态 | 触发 | 表现 |
|---|---|---|
| home | 默认在家 | 小屋轻微发光，角色偶尔探头 |
| idle | 常规待机 | 呼吸、眨眼、小幅摆动 |
| walk | 页面边缘巡逻 | 沿边框移动 |
| jump | 遇到阻挡 | 小跳跃越过 |
| teleport | 跨区域移动 | 虫洞出现，角色穿梭 |
| think | 用户运行 SQL 或 AI 思考 | 扶帽、看罗盘、符文旋转 |
| talk | 角色说话 | 气泡出现，嘴部或身体轻动 |
| happy | 成功事件 | 挥手、眼睛发光 |
| confused | 错误事件 | 歪头、冒问号 |
| sleep | 用户长时间无操作 | 靠着小屋睡觉 |
| level-up | 升级 | 光效、台词、形态提示 |

## 6. 升级 MVP

### 6.1 经验来源

| 事件 | 经验 |
|---|---:|
| 打开 SQL Lab | +1 |
| 运行查询 | +2 |
| 查询成功 | +3 |
| 查询失败后修复成功 | +5 |
| 使用 SQL Assistant | +2 |
| 与 Guardian 对话 | +2 |
| 写文章或笔记 | +3 |
| 更新简历 | +3 |
| 记录求职进度 | +2 |

### 6.2 等级阈值

| 等级 | 所需累计经验 | 名称 |
|---:|---:|---|
| 1 | 0 | 迷失的数据水手 |

第一版只需要 Lv.1 - Lv.5。后续可扩展。

## 7. 验收标准

### 7.1 工程验收

- `npm run lint` 通过。
- `npm run build` 通过。
- `npx prisma generate` 通过。
- 如果新增迁移，`npx prisma migrate dev` 通过。
- 无 TypeScript 明显类型错误。
- 无未授权 API 访问。

### 7.2 产品验收

- 用户能看到角色之家。
- 用户能点击角色对话。
- 角色能显示至少 5 种状态。
- 每个用户的等级、心情、人格独立。
- 角色能记住一条偏好并在后续对话中提起。
- SQL Assistant 回答风格有轻微人格化。
- 用户能关闭动画或隐藏角色。

### 7.3 安全验收

- 未登录不能读取 GuardianProfile。
- 用户不能读取其他用户 GuardianMemory。
- Guardian 不能绕过 SQL Lab 表权限。
- Guardian 不能绕过列屏蔽和行过滤。
- Guardian 的 AI 调用受现有 provider、权限、审计约束。
- 敏感记忆不自动保存。

### 7.4 体验验收

- 不遮挡 SQL 编辑器输入。
- 不遮挡 Run / Format / Save 等关键按钮。
- 移动端默认收起或简化。
- reduced motion 下禁用复杂动画。
- 角色自言自语频率可接受。

| 阶段 | 名称 | 目标 |
|---|---|---|
| P0 | 代码扫描与文档校准 | 找准真实路径 |

| P2 | 动画状态机 | 角色能动、能说话 |
| P3 | 数据模型与 API | 每用户独立数据持久化 |
| P4 | 聊天 | 可对话、可保存对话 |

| P6 | 成长系统 | 活动产生经验、升级 |
| P7 | 蝶灵共享记忆 | 授权读取共享上下文 |
| P8 | 美术替换和打磨 | 真实 2D 资产、移动端、性能 |
